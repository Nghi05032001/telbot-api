📌 Tài liệu Tích Hợp API Đại Lý

Chào mừng các đối tác đại lý! Dưới đây là toàn bộ tài liệu hướng dẫn kết nối hệ thống tự động hóa mua hàng qua API của chúng tôi.

1. Thông số kết nối chung (Base URL)

http://163.61.182.107

2. Danh sách Endpoints API

GET A. Kiểm tra thông tin & số dư đại lý

  • Đường dẫn: http://163.61.182.107/api/info?api_key=API_KEY_CUA_DAI_LY
  • Mô tả: Trả về thông tin số dư tài khoản, mã định danh và danh sách sản phẩm cùng mức giá, số lượng tồn kho.
  • Ví dụ Response (JSON):
{
    "status": "success",
    "user_id": 8893370969,
    "balance": 49600,
    "products": {
        "canva": {
            "name": "Mailedu 7days",
            "price": 200,
            "stock": 6879
        },
        "netflix": {
            "name": "Mailedu 24h",
            "price": 150,
            "stock": 0
        }
    }
}

POST B. Mua sản phẩm tự động

  • Đường dẫn: http://163.61.182.107/api/buy
  • Headers: Content-Type: application/json
  • Dữ liệu gửi lên (Body JSON):
{
    "api_key": "API_KEY_CUA_DAI_LY",
    "product": "canva",
    "quantity": 1
}

3. Mã Code Mẫu Tích Hợp (Python)

Đại lý có thể sử dụng đoạn code mẫu dưới đây để tích hợp trực tiếp vào hệ thống bot hoặc ứng dụng riêng:

import requests

# Thay API key của bạn vào đây
API_KEY = "API_KEY_CUA_DAI_LY"
BASE_URL = "http://163.61.182.107"

# 1. Kiểm tra thông tin tài khoản & số dư
def check_info():
    response = requests.get(f"{BASE_URL}/api/info", params={"api_key": API_KEY})
    print(response.json())

# 2. Mua hàng tự động
def buy_product(product_code, quantity=1):
    payload = {
        "api_key": API_KEY,
        "product": product_code,
        "quantity": quantity
    }
    response = requests.post(f"{BASE_URL}/api/buy", json=payload)
    print(response.json())

if __name__ == "__main__":
    check_info()
